# Publishing this repo and submitting

## 1. Push to GitHub
1. On github.com click **New repository**, name it `Cyber-Security-Projects-Codec-2026`, keep it **Public**, and do NOT tick "Add a README" or "Choose a license" — both are already in this folder. Create it.
2. In a terminal inside this unzipped folder:
   ```bash
   git init
   git add .
   git commit -m "Cyber security internship projects - all 20"
   git branch -M main
   git remote add origin https://github.com/<your-username>/Cyber-Security-Projects-Codec-2026.git
   git push -u origin main
   ```
3. Open the repo and check the project READMEs render with their result images (relative paths, so they show automatically).
